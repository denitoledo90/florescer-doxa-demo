# Florescer · EmpatIA × Doxa

Protótipo educativo de cuidado, reflexão e liderança, preparado para demonstração com dados fictícios.

- A conversa é inspirada no WhatsApp, mas não envia mensagens nem está conectada ao WhatsApp ou à EmpatIA.
- A configuração semanal de IA é uma proposta preparada para Azure OpenAI; a versão publicada neste site não está conectada a um serviço de IA.
- DISC e CliftonStrengths servem de inspiração para perguntas editoriais; a demonstração não aplica avaliações oficiais nem oferece diagnóstico.
- Não há autenticação ou proteção adequada para dados reais. Use somente informações fictícias.

O Leia-me dentro do aplicativo explica as adaptações, limitações e os cuidados necessários antes de um piloto real.
